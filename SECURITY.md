# Security

This repository contains a static gallery and a local-only demo. It has no
backend, production credentials, user accounts or database connection.

Please do not disclose vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository when that feature is
enabled. Reports about the live game must not include exploit details in
this showcase repository.

The supported code is the current default branch. The demo is illustrative
and is not a production game service.
